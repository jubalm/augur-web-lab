# Augur website

The website explains Augur's decentralized oracle infrastructure, proposed Augur Lituus mechanism, related products, REP and the work underway. It is an informational static site, not a trading interface or deployed oracle application.

It provides `/`, `/about/`, `/products/`, `/learn/`, guide routes, `/rep/`, `/blog/`, article/category/pagination routes, `/faq/`, `/contact/` and an on-brand 404. The header and footer share one navigation directory. Every route uses the fixed Navy system and accessible responsive controls.

The homepage establishes the problem, shows illustrative application questions, explains reporting and challenges, describes optional REP participation, gives sourced roadmap evidence, and points to writing and FAQs. Secondary pages deepen those topics without introducing unsupported capability claims.

Content remains explicitly gated for release: stand-in articles and guides, FAQ review entries, product status and payout confirmation, contract addresses, newsletter consent/provider, inbox ownership and indexing. See `docs/launch-checklist.md`.
